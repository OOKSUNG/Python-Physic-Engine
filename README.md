# Python-Physic-Engine

Physics and collision system project developed with Python and pygame.

Project for the Introduction to Game Programming course at Kyung Hee University.

## Project Overview

This project implements a simple 2D physics and collision system using Python and pygame.

The project focuses on collision detection, object movement, and basic physics simulation.

---

## Tech Stack

- Python
- pygame

---

## Features

### Collision System
- AABB collision detection
- Collision response handling
- Object overlap detection

### Physics System
- Gravity simulation
- Velocity and acceleration update
- Physics update loop

### Object System
- Dynamic object movement
- Boundary collision handling
- Multiple object interaction
